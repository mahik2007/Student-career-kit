# 01 · THE GAP

Students often need to prepare resumes, cover letters, LinkedIn profiles, project descriptions, recruiter emails, and GitHub documentation separately.

Their career information is scattered across documents, notes, repositories, and application forms.

Student Career Kit aims to bring these tasks into one organized workspace.
